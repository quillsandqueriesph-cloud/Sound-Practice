Five sound categories

Speech
Person talking or singing where words can be made out.
Music
Music of any kind.
Event
Distinct sound from one identifiable source with a start and end.
Ambience
Continuous background/environmental sound.
Artificial
Synthetic/digitally created sound added to the scene.
GUIDED PRACTICE

Practice clips

Add clips learners will use before the final assessment. Use a direct media URL, a hosted MP4/WebM URL, or another browser-playable media source. The URL must permit browser playback.

Practice modes: Identification = identify categories present. Classification = classify a target sound. Segmentation = mark one target sound precisely. Full annotation = identify and annotate multiple sounds across all five timeline lanes.

Configured practice clips

Practice answer key

Select a practice clip and configure what counts as correct. These keys are used for immediate practice feedback only and are not submitted as learner data.

KNOWLEDGE CHECK

Multiple-choice question bank

Import a CSV or add questions manually. The CSV format is: question,optionA,optionB,optionC,optionD,correct,explanation. Correct can be A/B/C/D or the exact option text.

FINAL ASSESSMENT BUILDER

Configure the actual assessment

Only this tab's responses are sent to the data endpoint. Practice activity is not submitted as an assessment record.

Final segmentation answer key

Add every expected segment. Start/end values are in seconds. Only the final assessment uses these answers for scoring and data collection.

Assessment rules

The final assessment will contain two components: (1) multiple-choice knowledge questions and (2) an actual interactive segmentation item. Name and email are collected only when the learner enters the final assessment.
DATA COLLECTION

Google Sheets connection

Use a Google Apps Script Web App as the secure submission receiver. The exported game sends a JSON assessment record to the URL below.

Recommended sheet columns: timestamp, attemptId, name, email, assessmentVersion, mcqScore, mcqTotal, detectionScore, classificationScore, timingScore, namingScore, overallScore, submittedAt, answersJson, annotationsJson.

One-attempt protection

The exported assessment first asks the endpoint whether the email/access token has already been used. The server must reject duplicate submissions. The browser also disables the assessment after a successful submission, but that browser lock is only a convenience layer.

For a stronger deployment, restrict the Apps Script Web App to the intended users/domain and use an access token or organization-issued identifier in addition to email.
